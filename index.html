FPL Auto-Manager

Python · LightGBM · PuLP · GitHub Actions · Telegram · OCR

A Fantasy Premier League bot that predicts every player's points, plans transfers, captain and chips four weeks ahead, and runs every hour on GitHub Actions.

Decision log
  1. Two-stage model: chance a player plays × points if he plays, so rotation risk is modelled directly.
  2. Caught a data leak: a community dataset's "expected points" column was recorded after the matches, so benchmarks against it only use clean 2025/26 data.
  3. Cheap check first: a tiny standard-library script runs hourly and only wakes the heavy pipeline near a deadline.
  4. No password stored: my real team is read from a screenshot with OCR instead of logging in.
Code available on request

Football xG Lab & Scout

Python · LightGBM · Streamlit · GitHub Actions

An expected-goals model on free StatsBomb data that matches StatsBomb's commercial model on World Cup 2022, Euro 2024 and Copa América 2024, plus a similar-player finder.

Decision log
  1. Split by match, not by shot, so shots from the same game never leak between training and test.
  2. Used freeze frames (where every player stood at the moment of the shot) as features, not just shot location.
  3. Claimed "matches", not "beats": the paired bootstrap's confidence interval includes zero.

Safety & guardrails

how I build AI systems
01

Rules decide, models explain

Verdicts, amounts and deadlines come from deterministic code. The LLM explains the result and drafts the message.

02

A person approves outbound actions

Agents prepare emails, complaints and writes; nothing reaches a customer without an approval step.

03

Fail closed

If a compliance check can't run, the answer is "no", not "probably fine".

04

Evals gate releases

A release ships only if safety, citation accuracy and quality clear fixed bars against the previous version.
