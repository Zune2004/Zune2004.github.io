Projects

FPL Auto-Manager

Python, LightGBM, PuLP, GitHub Actions, Telegram, Tesseract

A bot that manages my Fantasy Premier League team. It predicts every player's points, plans transfers, captain and chips four weeks ahead, and messages me on Telegram before each deadline. It runs every hour on GitHub Actions.

Decisions along the way
  • Two models instead of one. One predicts whether a player plays, the other how many points he scores if he does. Rotation risk gets modelled directly.
  • Found a leak in a popular dataset. Its "expected points" column was recorded after the matches, so I only compare against it on clean 2025/26 data.
  • Cheap check first. A small script runs hourly and only starts the full pipeline when a deadline is close.
  • No password stored. It reads my real team from a screenshot instead of logging in to FPL.

Football xG Lab and Scout

Python, LightGBM, Streamlit, GitHub Actions

An expected-goals model trained only on free StatsBomb data. On World Cup 2022, Euro 2024 and Copa América 2024 it performs as well as StatsBomb's commercial model. Scout finds players with a similar statistical profile across Europe's top leagues.

Decisions along the way
  • Split by match. Shots from one game never appear in both training and test data.
  • Used freeze frames. The model sees where every player stood when the shot was taken.
  • Careful wording. A paired bootstrap shows the gap to StatsBomb isn't significant, so I say the models are level.

How I build AI

Code makes the decisions. Amounts, verdicts and deadlines come from plain, tested code. The model explains the result and drafts the message.

People approve what goes out. Agents prepare emails and changes; a person signs off before anything reaches a customer.

When unsure, refuse. If a compliance check can't run, the answer is no.

Evaluations decide releases. A new version ships only if it clears fixed bars for safety, accuracy and citations against the last one.
