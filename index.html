FPL Auto-Manager

A bot that manages my Fantasy Premier League team. It predicts every player's points, plans transfers, captain and chips four weeks ahead, and messages me on Telegram before each deadline. It runs every hour on GitHub Actions.

Football xG Lab and Scout

An expected-goals model trained only on free StatsBomb data. On World Cup 2022, Euro 2024 and Copa América 2024 it performs as well as StatsBomb's commercial model. Scout finds players with a similar statistical profile across Europe's top leagues.

How I build AI

Code makes the decisions.

Amounts, verdicts and deadlines come from plain, tested code. The model explains the result and drafts the message.

People approve what goes out.

Agents prepare emails and changes; a person signs off before anything reaches a customer.

When unsure, refuse.

If a compliance check can't run, the answer is no.

Evaluations decide releases.

A new version ships only if it clears fixed bars for safety, accuracy and citations against the last one.
